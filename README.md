# 🎒 Rutas Mochileras Store

Tienda multirubro en Caracas (Chacaíto) con Landing Page responsive, catálogo por categorías y backend de administración de productos.

## 📁 Archivos Creados

- **`index.html`**: Landing Page con Catálogo, Carrito de compras, selector de asesores WhatsApp, Modo Oscuro/Claro, indicador de horario dinámico y Panel de Administración Backend.
- **`server.js`**: Servidor Node.js Express con API REST para carga de imágenes en disco duro.
- **`package.json`**: Dependencias para ejecución en servidor local o producción.
